# Notes for AI agents

- To cut a release, follow [RELEASING.md](RELEASING.md) step by step.
- Build and test locally with `scripts/build-local.sh` (builds into
  `.build/`, installs nothing).
- Open follow-up work (with context and where to start) is listed in
  [docs/FOLLOW-UPS.md](docs/FOLLOW-UPS.md); remove items as they are done.
- Run the tests with `scripts/run-tests.sh` (and `scripts/run-tsan.sh` for
  threaded code); see the README for the real-frame suite.
